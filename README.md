# poem-desk

A single-file page for sitting with a poem. Paste a poem in, switch to **Read** to see it set in a quiet serif with a margin beside it, select any words to leave a note, and copy the poem and your notes out as plain text — for example, to hand to an AI.

Everything lives in one `index.html` and is saved in your browser's local storage as you type. There is no server, no account and nothing is sent anywhere. (It loads three fonts from Google Fonts.)

Open `index.html` in a browser.
